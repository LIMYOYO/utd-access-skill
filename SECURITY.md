# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository rather than opening a public issue. Include the affected version, reproduction steps, impact, and any suggested mitigation.

Do not include real institutional credentials, cookies, MFA responses, signed download links, or copyrighted subscription PDFs in a report. Use synthetic values and redact temporary URL parameters.

## Scope

Security reports are especially useful for:

- native messaging host registration or extension-origin validation;
- unintended disclosure of credentials, session data, local paths, or downloaded files;
- unsafe URL handling, redirects, or local-network access;
- a download being associated with the wrong request or paper;
- commands or instructions executed from untrusted paper or webpage content.

The current supported preview is the latest GitHub prerelease on macOS and Google Chrome. Older development snapshots may not receive fixes.
